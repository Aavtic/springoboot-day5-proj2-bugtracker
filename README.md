# Bug Tracker

A simple Java bug tracking application that stores bug reports in a PostgreSQL database using JDBC and Maven.

## Features

- Add bug reports
- Store bugs in PostgreSQL
- JDBC database connectivity
- Maven project structure

## Tech Stack

- Java 17
- PostgreSQL
- JDBC
- Maven
